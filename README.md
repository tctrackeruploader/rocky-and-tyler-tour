# Rocky and Tyler Tour

A preserved recreation of the 2015 **Rocky and Tyler Tour** website.

The original website was a simple tour announcement page featuring official artwork, an embedded video, and links to ticket and venue pages for the tour dates. This project recreates that page as closely as possible while keeping its original design, typeface, layout, and archived external links accessible.

## About

The Rocky and Tyler Tour paired A$AP Rocky and Tyler, The Creator for a 2015 run of North American dates.

This site preserves the original page’s structure:

- Tour artwork
- Embedded “ROCKY AND TYLER” video
- Tour-date list
- Original venue and ticket destinations preserved through the Wayback Machine where possible
- Original Boxcutter typeface styling

## Preservation

The original site was archived by the Internet Archive’s Wayback Machine.

- Original website: [rockyandtyler.com archive](https://web.archive.org/web/20151012122105/http://rockyandtyler.com/)
- Original stylesheet archive: [style.css archive](https://web.archive.org/web/20150905153802cs_/http://rockyandtyler.com/style.css)
- Archived video embed: [ROCKY AND TYLER video](https://web.archive.org/web/20151012122105if_/https://www.youtube.com/embed/xT62uGlpXM0)

Some external ticket pages, venue websites, and video resources may no longer work exactly as they did in 2015. Archived pages can also have missing images, scripts, playback files, or ticketing features due to the way the web was captured.
